# 🧠 DSA in Java — Learning Repository

This is my personal DSA practice repository. I commit what I learn — no polish, no perfection, just consistent progress.

---

## 📂 Topics Covered

| Package | What's Inside |
|---|---|
| `LinearSearch` | Linear search, 2D search, two sum, min, max wealth |
| `BinarySearch` | BS variants — order-agnostic, rotated, duplicates, peak, sqrt, ceiling/floor, Koko problem, split array |
| `ArrRecursion` | Recursive binary search, linear search (all indices), check sorted, subsets, rotated BS |
| `Recurrsion` | Factorial, fibonacci, digit sum/product, palindrome, reverse number/string |
| `StringRecursion` | Subsequences, permutations, skip characters, dice combinations, keypad letter combos |
| `PatternRecursion` | Triangle patterns using recursion |
| `Sorting` | Bubble, selection, insertion, cyclic sort, Dutch national flag, missing/duplicate number problems |
| `SortingRecursion` | Merge sort (standard + in-place), quick sort, recursive bubble/selection sort |
| `Arrays` | Factors, greedy (can place flowers), product except self, sieve of Eratosthenes, subsets with duplicates |
| `Maze_Prblms` | Count paths, print paths, diagonal paths, obstacles, matrix path with steps |
| `Backtracking` | N-Queens, N-Knights, Sudoku solver, maze all-directions, subsets |
| `BInary2D` | Binary search in sorted matrix (row+col sorted, fully sorted) |
| `SlidingWindow` | Max average subarray, max vowels in substring |
| `MathsForDSA` | GCD, LCM, power, bit tricks (even/odd, set bits, XOR, power of 2), Newton's sqrt |
| `String` | Merge strings alternately, reverse words, string compression |

## 📌 Key Problems by Difficulty

**Good starting points:**
- `LinearSearch/TwoSum.java` — classic two-pointer warmup
- `BinarySearch/BS.java` — standard binary search
- `Sorting/BubbleSort.java` — basics of comparison sorting

**Interesting implementations:**
- `Backtracking/SudokuSolver.java` — full backtracking solver
- `Backtracking/NQueens.java` — classic N-Queens with count
- `BinarySearch/KokoPrblm.java` — binary search on answer
- `SortingRecursion/QuickSort.java` — in-place quicksort with pivot
- `Arrays/SubsetDuplicate.java` — iterative subsets handling duplicates

**Bit manipulation:**
- `MathsForDSA/FindUnique.java` — XOR trick to find unique element
- `MathsForDSA/Power.java` — fast exponentiation using bits
- `MathsForDSA/RangeXOR.java` — O(1) XOR over a range
